# mojo-json

mojo-json is a [JSON](https://en.wikipedia.org/wiki/JSON) serializer written in
[Mojo](https://www.modular.com/mojo). The runtime and the code generator are
Mojo. They do not wrap simdjson or any other C, C++, or Rust JSON library.
